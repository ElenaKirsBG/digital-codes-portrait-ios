# Портрет по цифровым кодам

Исправленная версия: календарная дата проверяется независимо от часового пояса;
ошибки ввода видны в форме; недоступный виброотклик не блокирует отчёт.

## Готовый сайт — ручная загрузка в GitHub
1. Распакуйте digital-codes-portrait-ios-ready.zip.
2. В ElenaKirsBG/digital-codes-portrait-ios выберите Add file → Upload files.
3. Загрузите СОДЕРЖИМОЕ архива в корень репозитория, а не ZIP и не внешнюю папку.
4. В корне должны быть index.html, 404.html, .nojekyll, папки _expo и assets.
5. Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. Открывайте адрес сайта, который покажет GitHub Pages после завершения публикации.

Обязательно сохраните файл .nojekyll: он разрешает раздачу папки _expo.
Для другого имени репозитория нужно изменить experiments.baseUrl в source/app.json и пересобрать сайт.
В архиве настроен путь /digital-codes-portrait-ios.

## Исходники
В готовом веб-архиве они находятся в source/. Отдельный source.zip содержит их в корне.
Исходники независимы от монорепозитория Replit: нет workspace:* и catalog:.
Все прямые версии зависимостей зафиксированы в package.json.
Для самостоятельной пересборки нужны Node.js 24 и npm:
npm install
npm run typecheck
npm run test:calculation
npm run build:web
Результат находится в dist/. Перенесите его в корень сайта и добавьте .nojekyll.
Для обновления прямых ссылок на отчёт скопируйте index.html также в 404.html.

Это веб-приложение и исходники Expo, НЕ подписанный IPA-файл.
На iPhone сайт открывается в Safari. Данные сохраняются локально в этом браузере.
Перед сменой адреса сайта, браузера или устройства создайте резервную копию.
Перечень источников — SOURCES.md. Исходные PDF и Excel с персональным примером не включены.
